# Data-Science-Tech-Scholarship
# Session 1 — Data Science Foundations

Welcome to Session 1 of **Tech Mentorship 2026**.

In this session, we'll build a foundation for understanding what data science is, how data professionals approach problems, and how different tools fit into the data ecosystem.

We'll also get practical by working with a real-world dataset using **Python and Google Colab**.

## What We'll Cover

* What data science is and where it fits into real-world work
* The data science workflow
* Why real-world data is messy
* Different tools used in data work, including Excel, SQL, Python, Pandas, visualization, statistics, and machine learning
* How different data professionals use these tools
* Getting started with Python for data exploration
* A practical introduction to working with the Olist dataset

## Practical Session

During the practical portion, you will:

1. Open Google Colab.
2. Load the assigned Olist dataset.
3. Display the first few rows.
4. Use `shape`, `info()` and `describe()` to inspect the dataset.
5. Identify things you notice about the data.
6. Think of questions that could be investigated using the dataset.

## Dataset

**Olist Dataset:** Use the dataset link provided in the presentation/resources.

## Tools

* Olist dataset

## After the Session

Complete the **Session 1 Assignment** in this folder and use what you learned during the practical exercise to answer the questions.

Have fun exploring the data — there isn't always one "correct" thing to notice or one perfect question to ask. The goal is to start thinking about data like a data professional.
